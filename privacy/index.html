기기에 저장되는 정보
앱을 빠르게 열고 오프라인에서도 쓸 수 있도록 앱 파일을 브라우저 캐시에 저장합니다. 이 정보는 사용자의 기기 안에만 있으며, 브라우저 설정에서 사이트 데이터를 지우면 함께 삭제됩니다.

사용자가 입력하는 정보
앱 안에서 입력한 이름 같은 내용은 화면에 보여 주는 데만 쓰이고 서버로 보내지 않습니다.

외부 서비스
사이트는 GitHub Pages에서 제공되고, 글꼴은 Google Fonts에서 불러옵니다. 이 과정에서 각 서비스가 접속 기록(IP 주소 등)을 처리할 수 있으며, 이는 해당 서비스의 정책을 따릅니다.
